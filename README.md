A modern, responsive landing page and web application modeled with the design philosophy and animation architecture of **Hack2skill**, customized for **Vantri (V3)**.

---

- **V1 — Vision:** Foreseeing technological disruption and identifying future-proof opportunities.

## 🎨 Key Features

- **Infinite Scrolling Marquee:** GPU-accelerated CSS marquee with technology logos and names, auto-pausing on hover.
- **Ratio-Adaptive Design:** Designed using fluid sizing (`clamp()`, responsive flex/grid) to guarantee optimal viewing on mobile, tablet, laptop, and ultra-wide screens.
- **Interactive Modals:** Dynamic enrollment and inquiry popup with context pre-filling.
